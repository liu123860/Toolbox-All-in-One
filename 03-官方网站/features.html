功能详情

自研轻量实现 + 开源专业组件容器集成，两条路都保证"点得开、用得上"。

🧮 生活工具

计算器：AST 安全求值，支持括号、幂、开方、三角函数与历史记录，拒绝任意代码执行。
天气：Open-Meteo 主源 + wttr.in 自动回退，7 日预报，离线显示上次缓存。

📝 办公工具

文档编辑：txt / md / html / rtf / docx 读写，可交由 LibreOffice 容器接管复杂排版。
PDF 阅读：QtPdf 内置引擎。
AI 助手：多模型接口，密钥 Windows DPAPI 加密，未配置时可演示。

🎬 媒体工具

音乐 / 视频：QtMultimedia 内置引擎 + 播放列表，检测到 VLC 便携版后自动接管全格式。
高清转码：FFmpeg 容器 H.264 / H.265。

🛠 系统工具

浏览器：Chromium 内核多标签页。
垃圾清理：白名单目录只读扫描，二次确认后送回收站。
病毒扫描：ClamAV 容器或明确标注的轻量启发式，隔离可恢复。
压缩解压：Zip-Slip 防护。
扫描打印：打印预览 + WIA 扫描。

容器式集成：专业软件装进"盒子"

不捆绑任何商业软件；开源组件的便携版放进 vendor 目录即被主程序接管，没有组件时自动降级到内置实现。

能力首选开源组件无组件时的内置降级许可证处理

全格式播放VLC 便携版QtMultimedia子进程隔离
