安装与使用提示

获取安装包

下载安装程序，或解压 zip 便携版到任意文件夹。

首次启动

按提示设置主管理员密码（只存加密哈希，请牢记）；之后可用 15 天免登录或注册普通账号。

开始使用

在主界面点击工具图标即可打开；右上角可进设置与管理入口。

关于 Windows SmartScreen / 杀软提示：当前版本尚未完成代码签名（SignPath Foundation 申请审核中），首次运行可能弹出"Windows 已保护你的电脑"，点「更多信息 → 仍要运行」即可；签名通过后发布的版本将不再提示。详见下方 Code signing policy。
系统要求：Windows 10 / 11（64 位）；无需预先安装 Python；浏览器工具内置 Chromium 内核；约需 1 GB 磁盘空间。天气工具需要联网，离线时显示上次缓存。

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. Status: Pending approval — 当前发布版本尚未签名，随包提供 SHA-256 校验值。

所有发布产物均由本公开仓库的 GitHub Actions 在 GitHub 托管 runner 上自动构建， 仅 CI 构建的产物会提交签名，每次发布需人工批准；私钥由 SignPath 的 HSM 保管。 查看完整签名策略 · 隐私政策
